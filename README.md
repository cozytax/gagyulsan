# 가결산 리포트 (웹)

손익계산서 PDF를 올리면 **12개월 환산 → 3개년 추이 → 진단·피드백 → A4 3장 보고서(표지 포함)** 를 만들어 PDF로 저장하는 프로그램입니다.
서버가 필요 없는 정적 웹페이지라서 폴더째 공유 드라이브에 두고 `index.html` 을 열기만 하면 됩니다.

## 배포 (직원 공유)

- **링크로 쓰기**: `배포방법.md` 를 보고 GitHub Pages(무료)나 Netlify 에 올리면 `https://…` 링크가 생깁니다. 올릴 때 `sample/` 폴더(거래처 자료)는 제외.
- **링크 없이**: 이 폴더 전체를 공유 OneDrive 폴더에 두고 각자 `index.html` 을 Chrome/Edge 로 더블클릭.
- 인터넷 연결 필요(글꼴·PDF 라이브러리를 CDN에서 받음). 외부인 차단이 필요하면 `js/config.js` 의 `accessCode` 에 암호 입력.

## 사용 순서

1. **PDF 올리기** — 올해(가결산) 손익계산서를 올립니다. 비교식(당기·전기 2열) 양식이면 한 파일로 2개년이 읽힙니다.
   작년·재작년 파일을 더 올리면 최대 3개년을 비교합니다. 같은 연도가 겹치면 그 연도 파일의 '당기' 열을 우선합니다.
2. **보고서 정보** — 회사명(PDF에서 자동), 세무사무소, 담당자, 보고일, 제목(가결산/중간결산/경영성과 보고서).
3. **예상 세금 설정** — 법인/개인(자동 감지), 공제·감면율, 이월결손금. 보고서에서 세금 표를 뺄 수도 있습니다.
4. **읽어낸 숫자 확인** — 파싱된 숫자를 표에서 확인하고 틀리면 직접 고칩니다(노란 칸). PDF가 없는 연도는 "연도 직접 추가"로 손입력.
5. **PDF 저장 / 인쇄** — 브라우저 인쇄창에서 대상 **"PDF로 저장"**, 여백 **없음**, **배경 그래픽 켜기**. 파일명은 `회사명_2026년 가결산 보고서` 로 자동 제안됩니다.

## 12개월 환산 방식

가장 최근 연도의 실적 개월 수(예: 1~9월 = 9개월)를 회계기간 문구에서 읽어 `12 ÷ 개월수` 를 곱합니다(단순 비례).
개월 수가 잘못 읽혔으면 "읽어낸 숫자 확인" 표 맨 아래 **실적 개월 수** 칸에서 고치면 됩니다.

## 지원하는 PDF

- 세무프로그램(더존·세무사랑 등)에서 출력한 **텍스트가 살아있는** 손익계산서 PDF. 스캔 이미지 PDF는 읽지 못합니다.
- 계정명이 "매 출 액" 처럼 띄어져 있어도, 숫자가 한 글자씩 쪼개져 있어도 인식합니다.
- 대분류(Ⅰ.매출액 ~ Ⅹ.당기순이익)와 판관비 세부 항목을 읽습니다. 총이익·영업이익 등이 빠져 있으면 자동 계산합니다.
- 회계기간은 "제N(당)기 YYYY년 M월 D일부터 YYYY년 M월 D일까지" 문구로 읽습니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 화면 |
| `css/app.css` | 작업 화면 스타일 (인쇄 시 숨김) |
| `css/report.css` | 보고서 A4 디자인 + 인쇄 설정 |
| `js/config.js` | **세율표·사무소명·진단 기준값** (수정은 여기서) |
| `js/parser.js` | PDF → 손익 데이터 (pdf.js) |
| `js/analysis.js` | 연도 병합, 환산, 비율, 진단 문구, 예상 세액 |
| `js/report.js` | 보고서 3장 HTML + 추이 차트(SVG) |
| `js/app.js` | 화면 동작 |
| `assets/` | 편한세무회계 로고(표지·바닥글·상단바) |
| `sample/` | 테스트용 샘플 PDF — 인터넷에 올리지 말 것 |
| `배포방법.md` | 링크로 배포하는 방법 |

## 유의사항

- 세율표는 `js/config.js` 의 값이며 **귀속연도 세법 개정 여부를 확인**한 뒤 사용하세요.
- 예상 세금은 기본세율만 적용한 단순 추정입니다(세무조정·공제감면·기납부세액 미반영).
- 테스트용으로 `index.html?load=sample/파일명.pdf` 처럼 주소에 붙이면 해당 PDF를 자동으로 불러옵니다.
- css/js 를 고쳐서 다시 올릴 때는 `index.html` 의 `?v=3` 숫자를 하나 올리세요(직원 브라우저가 옛 파일을 캐시하지 않도록).

## 담당자 코멘트

5번 칸에 코멘트를 쓰면 보고서 3쪽 예상 세금 표 아래(면책 문구 위)에 '담당자 코멘트' 상자로 들어갑니다. 줄바꿈 그대로 출력되고, 비우거나 '없음'을 고르면 상자 없이 기존처럼 출력됩니다.

## 추가 비용 시뮬레이션

4번 칸에 올해 안에 추가로 반영할 비용(대표 급여, 퇴직연금, 비품 구입 등)을 항목별로 넣으면, 보고서의 예상 세금 표가 **반영 전 / 반영 후 / 차이** 비교표로 바뀌고 절세 효과 상자와 진단 포인트가 함께 들어갑니다. 추가 비용은 12개월 환산 세전이익에서 그대로 뺍니다(환산하지 않음).
